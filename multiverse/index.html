MULTIVERSE

Une histoire, tous les points de vue.

Ajoutez les VOD de plusieurs streamers (YouTube ou Twitch) et l'heure réelle à laquelle chaque VOD a commencé. MULTIVERSE les aligne sur une horloge commune : changez de POV sans perdre le fil.

--:--:--

Ajouter un POV

Astuce : le début réel se trouve sur la page de la VOD. Pour caler finement, placez-vous sur un même moment dans deux POV, puis recalez avec −1s / +1s sur la carte. La durée réelle est relevée automatiquement à la lecture.

Moments clés

    Marquez les moments forts avec « + Moment ». Ils sont inclus dans le lien partagé.
